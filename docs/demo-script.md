# Demo Script

1. Run `make seed-demo`, `make backend-dev`, and `make frontend-dev`.
2. Open the home dashboard and select Demo AgentOps Quality Studio.
3. Show prompt versions and datasets from the project subpages.
4. Run a mock eval and open the latest run detail page.
5. Show pass rate, average score, p95 latency, estimated cost, failed cases, and trace links.
6. Open a trace and walk through the waterfall.
7. Run a second eval and open the comparison page to discuss regression detection.
8. Open Observability to show trace count, success rate, latency by span type, and estimated cost.
9. Open Failures to discuss missing citations, wrong tools, JSON invalid output, and recommendations.
10. Open Reports to show Markdown and HTML report artifacts.
11. Explain that all data is local files and mock mode works without keys.
12. Explain that OpenAI mode is opt-in with small defaults and compact judge outputs.
