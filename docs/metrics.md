# Metrics

- Pass rate: passed cases divided by total cases.
- Average score: mean of case average evaluator scores.
- p50 and p95 latency: percentile latency across case results.
- Estimated cost: provider-estimated token cost, marked as estimated.
- Failure rate: failed cases divided by total cases.
- Evaluator breakdown: mean score per evaluator.
- Regression metrics: pass-rate, score, latency, and cost deltas between runs.
- Quality gate metrics: threshold outcomes and blocked failure categories.
